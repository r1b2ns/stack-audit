## 0.1.0

- First release on pub.dev, in beta.
- `StackAudit.start` with secret masking, access modes, retention and size limits.
- `StackAuditHttpClient` records requests made through `package:http`.
- `StackAuditDioInterceptor` records Dio requests.
- Analytics events, feature flags with local overrides and key-value storage changes.
- On iOS, URLSession traffic from native code and plugins is recorded too.
- Example app with one screen per kind of capture.
